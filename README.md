# 《文明遗物》Prototype 1：竖屏实时争域

这是依据 PRD、数值系统和 UI 规范实现的本地可玩良渚「水与玉」主线版本。它以竖屏三节点、180 秒、卡牌循环与动员力为实时引擎，并接入 40 节点文明地图主循环。

## 已实现

- 9:16 竖屏三线战场：上方敌方、下方我方、中部河流与双桥；
- 清晰的敌我色系、皇冠占点计分、三路控制条、单位阵营标识和生命条；
- 四张固定手牌、费用/生命/伤害/争夺数值、下一张预览与动员力进度条；
- 单位入场弹跳动效、拖放落点高亮和水面流动效果；
- 180 秒倒计时，前 120 秒每 2.8 秒恢复 1 点动员力，末 60 秒恢复速度翻倍；
- 三战略节点及 -100 至 +100 的控制值；
- 8 张初始卡循环、4 张手牌、卡牌费用与目标节点部署；
- 劳作者、搬运队、守卫、筑堤工、木栅、临时堆场、集中劳力、重新部署；
- 自动交战、守卫威慑、资源节点搬运加成、领袖聚力、玉璧/玉钺触发；
- 程序化乌墩对手、胜负结算和返回文明地图。
- 教学对局平衡：乌墩以同数值卡牌进行换线，但同时在场单位受限为 3，确保玩家可通过“先拿两点、守卫清线、设施固守”建立优势。
- Cocos Creator 3.8.8 原生项目入口：`cocos-mobile/`，含 1080 × 1920 Battle 场景、战斗控制器和原生战场资源；
- 手绘良渚湿地战场底图：`assets/liangzhu-arena-cocos-v1.png`。
- 文明地图、40 个固定主线节点、资源与文明六维、本地存档；
- 卡组、聚落建设、外交/路线抉择、核心文物和文明卷宗页面；
- 工程、运输、危机、生产、终局保全五种独立目标；第 32 节点会依据文明路线选择 Boss 条件；
- 从地图进入实时争域，胜利后返回文明地图并结算节点奖励；
- 外交条约进入资源周期结算，路线抉择解锁不同卡牌；第 39 节点只能从四类遗存中保全两类；
- 玉璧、玉钺、玉梳背、玉琮、三叉形玉器均有独立的战斗被动。

## 运行

在此目录启动任意静态 HTTP 服务，例如：

```sh
python3 -m http.server 4173
```

随后访问 `http://localhost:4173`。

## 已验证胜利路线

1. 从世界页点击“查看问题与方案”，再进入争域；
2. 按住劳作者占北岸、搬运队占南侧后松开部署；
3. 用筑堤工或守卫巩固其中一点；
4. 用搬运队和临时堆场反攻渡口；
5. 稳住任意两个节点至计时结束。
